# Operationalizing energy justice: Mapping Norwegian youth preferences for renewable energy transitions

This repository contains workshop content, including a slide deck, interactive activities, instructions on how to run the workshops, and the data analysis files associated with the questionnaires. The workshops were conducted as part of the interdisciplinary research project "Energy for Future," which aims to assess youth perspectives on Norway's future net-zero energy system.

The purpose of this repository is to facilitate running workshops with schools, understanding how to conduct quantitative analysis based on students' perspectives and preferences (through questionnaires), and conducting qualitative assessments of reflections. The repository will be maintained and updated as the project progresses, reflecting new data from ongoing workshops.

For suggestions, queries, or to report potential errors in the analysis, please submit a GitHub issue or email m.s.javed@its.uio.no.
